# Ordenacao de numeros em C

1-Criação dos vetores: O programa cria três vetores com os mesmos cinco números inteiros: 5, 2, 8, 1, 3.

2-Bubble Sort: Compara números vizinhos e troca suas posições quando estão fora de ordem.

3-Selection Sort: Procura o menor número do vetor e o coloca na posição correta, repetindo o processo.

4-Quick Sort: Escolhe um pivô, divide os números em grupos menores e maiores e ordena cada parte recursivamente.

5-Exibição dos resultados: Após a ordenação, o programa mostra os resultados dos três algoritmos na tela, todos em ordem crescente.
